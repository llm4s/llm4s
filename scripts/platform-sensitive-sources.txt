# the modules in `PlatformTests.wholeModules`, and the suites `PlatformTests.suites` names in other modules.
#
# scripts/check-platform-tests.sh fails when a main source file calls a platform-sensitive API (its PATTERN:
# processes, path separators, file permissions and links, temporary files, writing, moving or deleting files, file
# locks, SQLite, line separators, the OS name, the user's home), is outside the whole modules, and is not listed
# here - so such code cannot reach main without a test that runs on Windows. A listed file need not match the
# pattern: list any file whose behaviour differs by platform.
#
# Each line is `<path> <coverage>`; a path ending in `/` covers every file under it. The coverage is either
#   <module>:<suite>    a suite name (or glob) that PlatformTests.suites lists for that module, or
#   none: <reason>      nothing runs it on Windows, and why that is acceptable.
