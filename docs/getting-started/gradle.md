# Java + Gradle Quickstart

There is a standalone Gradle project that shows how to call LLM4S from Java located in the repository at:

`modules/samples/gradle-java/`

This sample demonstrates how to:
- Use the Kotlin DSL in `build.gradle.kts`
- Include the `core_3` LLM4S dependency
- Load configuration and interact with the LLM using the Scala API directly from Java

For instructions on how to run it, refer to the `README.md` inside that directory.
