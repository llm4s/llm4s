Agents can delegate to typed subagents and run across several machines, credentials are secrets, and the Kotlin API
is on Maven Central for the first time.

## What is new

- **Subagents:** `TypedAgent[I, O]` specialists offered through `AgentBuilder.withSubagents`, each in its own child
  thread with a token budget, supervision, cancellation with its parent and nested streams
  ([#2044](https://github.com/llm4s/llm4s/issues/2044)). The [delegation guide](/guide/agents/delegation) walks
  through them.
- **Agents across machines:** `PostgresCheckpointer` shares threads between runtimes, a durable run queue and
  `AgentWorker` take and recover runs, and each run is one OpenTelemetry trace
  ([#2129](https://github.com/llm4s/llm4s/issues/2129)); see [several machines](/guide/agents/multiple-machines).
- **Credentials and data protection:** credentials are `Secret`s, a key can come from a file (`apiKeyFile`) or an
  `ApiKeyProvider`, and console and OpenTelemetry tracing withhold message content unless you opt in
  ([data protection guide](/guide/data-protection)).
- **Providers:** xAI, Perplexity's Agent API, keyless Microsoft Entra ID for Azure OpenAI, web search for Anthropic
  and Gemini, one proxy and CA setting for every client, and your own HTTP client
  ([providers guide](/guide/providers)).
- **Java and Kotlin:** a Java agent builder, streaming, annotated tools, structured output into records and a RAG
  facade (`llm4s-java-rag`), and `llm4s-kotlin-api` is published ([Java guide](/guide/java)).
- **New experimental modules:** `llm4s-ox` (direct style), `llm4s-reactor`, `llm4s-capabilities`, `llm4s-prompt`,
  `llm4s-schema-iron`, `llm4s-tapir` and `llm4s-repl`, plus the Elasticsearch/OpenSearch and Redis vector stores and
  the `llm4s-doctor` setup checker.

## Upgrading

llm4s is still stabilising before 1.0, and 0.6.0 sets no binary-compatibility baseline: any release may break
([compatibility policy](/reference/compatibility-policy#versions)). 0.6.0 has more breaking changes than usual. The
ones most code meets:

- Credentials are `Secret`, not `String` ([migration note](/reference/migration#credentials-are-secret-1932)).
- Many data types are growth-safe: a private constructor and `copy`, with `with*` setters instead, which breaks
  `.copy(...)` and positional patterns. The [migration guide](/reference/migration) lists each type.
- Console tracing prints no content by default
  ([migration note](/reference/migration#console-tracing-prints-no-content-by-default-2311)).
- `llm4s-java-api` and the Spring Boot starter no longer bring the provider modules: add the one you use
  ([migration note](/reference/migration#llm4s-java-api-and-the-spring-boot-starter-no-longer-bring-the-provider-modules-1496)).

```sbt
libraryDependencies ++= Seq(

)
```
