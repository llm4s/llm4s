# People headshots

Canonical headshots used by both People pages. Use lowercase full names separated by hyphens, for example `christopher-wheeler.jpg`. Keep the actual image format in the extension (`.jpg`, `.jpeg`, or `.png`); do not change formats by renaming extensions.

Use `/people/<filename>` in `docs/people.md` and `docs/people/<filename>` in the root `people.md`. Reuse the same headshot wherever a person appears. Portrait sizing and cropping belong in the page markup.
