# Tutorials

The [getting-started pages](../getting-started/) show a first call and the [cookbook](../examples/cookbook) one
program per problem. A tutorial is the long form: one application, built a part at a time, where each part adds a
feature and ends with code you would ship.

| Tutorial | You build |
|---|---|
| [Build a support assistant](support-assistant/) | A customer-support assistant for a small online shop: answers, typed tickets, tools and an agent |

Every Scala block in a tutorial is compiled and run by a spec, so the code on the page is the code that works.
