- **Fixed** saving an image with no inline data no longer writes a 0-byte file as success, and both `saveToFile`s write a temporary file and move it into place instead of truncating the target; an OpenAI entry with neither `b64_json` nor `url` is a `Left`
  ([#3140](https://github.com/llm4s/llm4s/issues/3140); [Guide](docs/guide/image-generation.md#core-concepts)).
- **Changed** `GeneratedImage.asBytes`, which throws on invalid base64, is deprecated: use `bytes`, which returns a `Left` ([#3140](https://github.com/llm4s/llm4s/issues/3140)).
