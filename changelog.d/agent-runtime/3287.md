- **Fixed** a worker crash no longer spends one of an entry's `maxAttempts` (in-memory, SQLite, PostgreSQL): the crash is counted (`QueueEntry.crashes`) and given back,
  and an entry whose run crashes its worker every time is dead-lettered at `maxCrashes` ([#3287](https://github.com/llm4s/llm4s/issues/3287); [Guide](docs/guide/agents/multiple-machines.md)).
