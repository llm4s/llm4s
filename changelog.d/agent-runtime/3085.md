- **Fixed** the run queues (in-memory, SQLite, PostgreSQL) no longer let one tenant's entries on a thread id refuse, reveal or jump another's:
  `Reject` and `position` see only the tenant's entries, and an `Interrupt` goes ahead of its own tenant's only ([#3085](https://github.com/llm4s/llm4s/issues/3085)).
