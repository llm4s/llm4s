- **Fixed** an MCP tool result joins every content block in order; an image, audio, resource or resource link is described (type, MIME type, URI, an embedded resource's text),
  so a call that succeeded is no longer reported as failed because its first block was not text ([#3074](https://github.com/llm4s/llm4s/issues/3074)).
