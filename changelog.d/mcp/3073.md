- **Fixed** the MCP HTTP+SSE client transport implements the 2024-11-05 protocol, so it talks to legacy servers, `MCPServer`'s `{path}/sse` included; replies are matched by id, bounded in time and size,
  and read by an SSE parser shared with Streamable HTTP (`data:` with or without a space, multi-line data); an `endpoint` on another origin is refused ([#3073](https://github.com/llm4s/llm4s/issues/3073)).
