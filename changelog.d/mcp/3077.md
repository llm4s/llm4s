- **Fixed** the stdio MCP transport waits `MCPServerConfig.timeout` for a reply, writes the first request at once (no 10 s stall on a quiet server), answers a server's own requests instead of taking them for replies,
  delivers a reply written just before an exit, starts one process between racing calls, and on close stops every process the server started ([#3077](https://github.com/llm4s/llm4s/issues/3077)).
