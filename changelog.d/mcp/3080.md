- **Fixed** `MCPToolRegistry` no longer re-dials a dead server on every lookup (a 1 s backoff doubling to 60 s), contacts its servers in parallel, runs one refresh per server at a time, and `healthCheck` sends a `ping` (new `MCPClient.ping()`);
  **Added** `ToolHintSource` (core, experimental), which `MCPToolRegistry` implements, so `AgentBuilder.withTools(registry)` gives a trusted server's tools their annotated hints ([#3080](https://github.com/llm4s/llm4s/issues/3080)).
