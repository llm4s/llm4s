- **Fixed** every memory store passes one `MemoryStoreContract`: a re-stored id replaces its timestamp, an id-changing `update` is a `ValidationError`, a limit below 1 or a blank query finds nothing, Postgres's `store` bumps the version, and SQLite deletes are one transaction.
  `MemoryStoreConfig`'s `defaultEmbeddingDimensions`, `enableAutoCleanup`, `cleanupThreshold` and `production` are deprecated ([#3038](https://github.com/llm4s/llm4s/issues/3038)).
