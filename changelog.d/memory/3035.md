- **Fixed** `LLMMemoryManager.consolidateMemories` never merges memories of different conversations, users, entities or writers, so an erasure removes their summaries, records every source id (`ConsolidationProvenance`), and keeps the sources when a summary stopped at its token limit ([#3035](https://github.com/llm4s/llm4s/issues/3035); [Guide](docs/guide/agents/memory.md#memory-consolidation)).
