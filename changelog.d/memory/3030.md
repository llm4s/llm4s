- **Fixed** `PostgresMemoryStore` and `InMemoryStore.withEmbeddingService` embed every memory they write without an embedding, so what a manager or `SemanticMemoryMiddleware` records is found by `search`; `PostgresMemoryStore.embedAll` embeds older rows, and without a service `search` is a keyword search, not the newest rows ([#3030](https://github.com/llm4s/llm4s/issues/3030); [Postgres Memory Store](docs/reference/postgres-memory-store.md#search)).
