- **Fixed** memory vector search follows one rule: `(1 + cos) / 2`, a zero or non-finite vector left out, only the query's dimension compared. `PostgresMemoryStore` no longer fails on mixed dimensions or zero vectors,
  and gains `embeddingDimensions` (a typed, HNSW-indexed column) and `reembedAll`, as does `VectorMemoryStore` ([#3037](https://github.com/llm4s/llm4s/issues/3037); [Postgres Memory Store](docs/reference/postgres-memory-store.md#declaring-the-dimension)).
