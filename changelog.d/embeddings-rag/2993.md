- **Fixed** `PgVectorStore`, `PgKeywordIndex`, `PgSearchIndex` and `PgCollectionStore` write and read metadata with ujson: a quote, backslash, newline or tab
  no longer fails the `jsonb` write, a value such as `x","tenant":"other` can no longer add or override a key, and escaped values read back decoded ([#2993](https://github.com/llm4s/llm4s/issues/2993)).
