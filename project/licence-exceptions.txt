# Reviewed licence decisions for runtime dependencies of published llm4s-* modules (#2308).
#
# One entry per line: group:artifact | SPDX id | justification
# The SPDX id is the licence a review established, and must itself be on LicencePolicy.allowed: an entry records
# a licence the dependency's POM omits or names in a way the policy does not recognise; it never admits a denied one.
# It applies to every version of the artifact. An entry that matches no dependency fails `sbt licenseCheck`.

org.json:json | LicenseRef-Public-Domain | JSON-java (via Jedis, llm4s-vectorstore-redis) is dedicated to the public domain since release 20231013 (its LICENSE file and POM say "Public Domain"); earlier releases carry the JSON licence, which the policy denies, so never pin one
com.hubspot.jinjava:jinjava | Apache-2.0 | Jinjava (via jlama-core, llm4s-jlama; Jlama renders models' chat templates with it) is Apache-2.0 by its repository's LICENSE (github.com/HubSpot/jinjava); its POM declares none
com.google.re2j:re2j | BSD-3-Clause | RE2/J (via jinjava, llm4s-jlama) carries the Go licence, which is the BSD-3-Clause text (github.com/google/re2j LICENSE); its POM names it "Go License"
com.hubspot.immutables:immutables-exceptions | Apache-2.0 | HubSpot Immutables' exceptions (via jinjava 2.7.7, llm4s-jlama) are Apache-2.0 by the repository's LICENSE (github.com/HubSpot/immutables); its POM declares none
